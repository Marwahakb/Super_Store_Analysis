# 📊 Superstore Sales Analysis

## 📌 Project Overview
This project focuses on analysing Superstore sales data using Microsoft Excel and Power BI. The objective is to explore sales performance, profitability, and business trends through data cleaning, analysis, and interactive dashboards.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Advanced Excel
- Power BI
- Power Query

## 📂 Project Work

### 1. Excel Analysis
- Data cleaning and preparation
- Created Pivot Tables for data analysis
- Analysed sales and profit
- Created charts and visualisations
- Built an interactive Excel dashboard
- Added slicers for filtering data

### 2. Power BI Analysis
- Imported and transformed data
- Used Power Query for data preparation
- Created measures for sales and profit analysis
- Developed interactive visualisations
- Built a Power BI report

## 📈 Project Files
- `Sample - Superstore sales report.xlsx` – Excel analysis workbook
- `sales analysis.pbix` – Power BI report
- `Screenshots/` – Project dashboard screenshots

## 🎯 Key Learning Outcomes
- Practical experience in data cleaning
- Understanding Pivot Tables and data analysis
- Creating interactive dashboards
- Working with Power BI visualisations
- Developing analytical and problem-solving skills
